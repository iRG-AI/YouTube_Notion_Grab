FULL-STACK KNOWLEDGE AUTOMATION

YouTube → Notion AI 요약기
+ Obsidian LLM Wiki

본 프로젝트는 YouTube 재생목록의 영상을 Gemini AI로 자동 수집/요약하여 Notion DB에 저장하고, 이를 Obsidian으로 자동 동기화하여 최신 LLM Wiki 지식베이스를 유기적으로 구축하는 엔터프라이즈급 자동화 솔루션입니다.

Engine v2.1 (Active) Gemini 2.5 Flash

✨ 주요 기능 명세

본 파이프라인이 제공하는 고성능 자동화의 핵심 구성 기능들입니다.

🎥 YouTube 재생목록 자동 수집
YouTube Data API v3를 활용해 마스터 재생목록을 실시간 파싱하여 신규 영상 인제스트.
🤖 Gemini AI 무결성 요약
4,000토큰 확장 출력을 통해 영상 제목·메타데이터 기반의 끊김 없는 고품질 4섹션 요약 생성.
🛡️ Self-Healing 요약 검증
Notion 저장 전 필수 헤더 유실 여부를 자동 검사하고, 실패 시 Fallback 프롬프트로 최대 2회 재생성 보정.
📝 Notion DB 저장 & 중복 차단
정밀 제목 정규화(공백, 이모지, NFC 변환 대조) 엔진을 통해 1,912개 영상 중 중복 등록 100% 차단.
🔄 Obsidian 자동 증분 동기화
Notion 완료 즉시 Python 동기화 엔진(sync_obsidian.py)을 기동하여 로컬 마크다운 문서 및 MOC 링크 빌드.
🧠 Karpathy LLM Wiki Ingest
단편적인 동영상들을 넘어 엔티티(도구)와 개념(RAG 등 기술)을 자동 추출 및 지식 페이지에 누적 합성(Synthesis).
